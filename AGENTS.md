# Repository scope

This repository is the authoritative development and release source for Standalone DLSS Glass Cockpit Refresh. Implement, test, build, commit and push future standalone changes here. It is not an export or mirror of another project; builds must remain self-contained.

- Preserve original-code PolyForm Noncommercial licensing and all upstream licenses and notices.
- Keep OFXR separate and preserve user settings. Do not add capture/report features or keyboard shortcuts without an explicit request.
- Run the relevant checks documented in README.md before preparing a release. Offline tests must not modify a real MSFS or headset installation.
- Preserve development-build update safeguards. Official releases require explicit production configuration and signing as documented in standalone/PUBLISHING.md.
- Never commit private signing keys, credentials, personal settings or generated build artifacts. Keep release uploads separate from source pushes.
