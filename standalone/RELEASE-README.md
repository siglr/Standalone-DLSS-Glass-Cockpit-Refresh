GLASS COCKPIT REFRESH — QUICK START

Release v1.0.2.16. The app checks for updates at launch. Older apps may reopen
more than once to complete compatibility updates; no uninstall is required.

INSTALL
1. Extract the complete ZIP into its own folder outside MSFS.
2. Close MSFS and run Standalone-DLSS-Glass-Cockpit-Refresh.exe.
3. On Setup, select the folder containing FlightSimulator2024.exe.
4. Choose Standalone DLL, or ReShade add-on if you already have ReShade
   6.7 or newer installed with full add-on support. ReShade is not included.
5. Leave Latest official release selected and click Install. For offline use
   or rollback, choose a bundled or older version. Then start MSFS normally.

Use one installation mode only. To switch modes or uninstall, close MSFS
and use Setup. Settings are preserved; OFXR and Pimax settings are untouched.
Keep all package files together, including the Source code and licenses folders.

SETTINGS
Bundled graphics: unmodified official v1.0.2, standalone and ReShade add-on.
A newer verified release opens Setup and highlights Update once per session.
Open Settings after installation. Advanced and Experimental are optional.
For standalone mode, click the shortcut button to choose the key combination
that opens IFreemz's in-game settings window. Green tint is available there.
Use the shortcut while MSFS has focus. Official standalone v1.0.2 reloads
the INI before saving, preserving settings changed by this app.
For ReShade mode, edit settings here with MSFS closed; during a flight, use
the fix's panel inside ReShade.

TROUBLESHOOTING
- Installation blocked: read the file/product named in the message. Do not
  overwrite or delete an unfamiliar DLL. ReShade using dxgi.dll normally
  calls for ReShade add-on mode. See Help for other graphics tools.
- Download verification failed: keep the current installation and retry later.
  Official downloads must pass checksum verification.
- MSFS fails to start or screens look wrong: check Help and the Compatibility
  information on Setup. Uninstall through this app, then compare the same
  official version and mode installed manually using IFreemz's instructions.
  If manual installation works, report it to installer support. If it also
  fails, report it to IFreemz with the fix version, reproduction steps and
  glass-cockpit-dlss-fix.log from the game folder.
- Leave optional Dark screen fix OFF (the author default) if displays show
  glare errors. Include the official graphics version when reporting issues.
