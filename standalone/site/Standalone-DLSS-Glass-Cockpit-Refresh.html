From download to cockpit.

One complete package. Three simple steps.

Already using ReShade in MSFS? Do not install this standalone package. Use IFreemz’s original Glass Cockpit DLSS Fix add-on for ReShade instead, alongside your existing ReShade setup.

  1. Download & extract

    Download the ZIP above. Choose Extract All and save the complete folder somewhere writable, outside your MSFS Content folder.

    Keep all files and subfolders together. Don’t run the EXE from inside the ZIP.

  2. Close MSFS & install

    Open the extracted application:

    Standalone-DLSS-Glass-Cockpit-Refresh.exe

    Check the automatically detected MSFS 2024 game folder, then click Install. Use Browse if needed, and approve a Windows administrator prompt only if the folder requires it. The folder must contain FlightSimulator2024.exe: Xbox calls it Content; Steam uses its game folder.

  3. Start your next flight

    Launch MSFS as usual. Use DLSS or FSR upscaling in the simulator’s graphics settings.

    Leave the glass fix enabled. Start with the author’s defaults, then compare on/off while parked in your favourite aircraft.

Already using another glass-cockpit fix? Remove a duplicate glass fix first. If the installer finds conflicting mod files, review its backup-and-replace prompt before proceeding. Windows blocked the app? See the help below.

Or check it with Windows PowerShell

Open the folder containing your downloaded ZIP in File Explorer. Type powershell in its address bar and press Enter. Paste this command:

Get-FileHash -Algorithm SHA256 -LiteralPath '.\Standalone-DLSS-Glass-Cockpit-Refresh.zip' | Select-Object -ExpandProperty Hash

Compare all 64 characters with the published SHA-256 above. Uppercase and lowercase are equivalent. Change the filename if Windows added a suffix such as (1). If the hashes differ, do not run that download: check its version and download a fresh copy.

What changed to protect installation and updates?

From v0.1.9, installation and game-folder detection run directly in the application. The launcher no longer starts PowerShell or sends encoded shell commands. It requests administrator rights only when folder permissions require them.

The app verifies release signatures using a public key built into the launcher, checks every packaged file against a signed inventory, and keeps recovery copies during replacement. It accepts updates only from the fixed WeSimGlide HTTPS addresses. Your glass settings and uninstall backups are preserved.

This release signing is separate from Windows publisher signing. The EXE still has no trusted Authenticode certificate, so SmartScreen or antivirus alerts can remain. The graphics DLLs still hook MSFS rendering, as required by the fix. The ZIP includes SECURITY.md describing file changes, network access and these limits.

Already using v0.1.4 or later? Just open the app as usual. It will update automatically when the new release is available. No manual download, uninstall or reinstall is needed. The added signature protection takes effect automatically after this update.

A little help before take-off.

Installation help, compatibility and what to try if something goes wrong. For Windows warnings, check whether the message is about app reputation or an antivirus detection before deciding what to allow.

Something is wrong or MSFS crashes. How do I get support?

First compare with the original mod, installed and configured the original way through ReShade. This helps identify whether the problem is in the original fix or this standalone package.

  1. Close MSFS and use this app’s Uninstall button. Keep this package uninstalled during the comparison; turning its checkbox off does not fully unload it.
  2. Install IFreemz’s original Glass Cockpit DLSS Fix through ReShade, following the author’s installation instructions. Configure it through the original ReShade settings menu, then try the same aircraft and situation.
  3. If the original mod works but this package does not, contact me on the WSG Discord. You can find the Discord link on the WeSimGlide website. Tell me that you tested the original ReShade version and explain what worked differently.
  4. If the problem also occurs with the original add-on, follow the author’s troubleshooting and bug-report instructions and report it to the original author.

For crashes, also test MSFS without either fix. If it still crashes, investigate the simulator, drivers and other add-ons first; that result does not establish a bug in the glass fix.

Include the mod version, aircraft, desktop or VR setup, DLSS/FSR settings, frame generation, other add-ons and the steps that reproduce the crash.

Do I need a particular DLSS preset or quality mode?

No particular DLSS preset is required. Keep the preset that works best for your setup. The original fix supports all DLSS quality modes, including DLAA, and also supports FSR.

Quality modes such as Quality, Balanced and Performance are different from DLSS model presets such as J, K or M. The fix redraws instrument content after upscaling, so it does not depend on choosing one specific model preset. This is not a guarantee that every driver override or future preset has been tested; image quality can still vary.

Use DLSS or FSR as the simulator’s anti-aliasing/upscaling mode. Enabling frame generation alone while using TAA is not enough. See the original mod’s documentation.

Does this work with Microsoft Flight Simulator 2020?

No. This package supports MSFS 2024 only. The original add-on targets MSFS 2024’s cockpit rendering; packaging it with ReShade components does not add MSFS 2020 support.

MSFS 2020 compatibility is outside this package’s scope. There is no installer setting or DLSS preset that enables it. Original mod requirements.

Windows SmartScreen says “Windows protected your PC”

If you downloaded this package from WeSimGlide.org and trust its source, you can approve this specific app:

  1. Choose More info in the SmartScreen warning.
  2. Check that the named app is Standalone-DLSS-Glass-Cockpit-Refresh.exe.
  3. Select Run anyway, if offered. An administrator prompt is used only if changing the simulator folder requires it.

This is an approval for the app; you do not need to turn SmartScreen off. If there is no override, your device’s policy or Smart App Control may be blocking it. On a managed PC, ask the administrator. Don’t disable system-wide protections just to run the mod.

Antivirus quarantined the EXE or one of the mod’s DLLs

A detection can be a false positive, but don’t assume that every alert is harmless. First update your antivirus definitions, check the exact file and detection name, and make sure the ZIP came from this page.

During the current vendor review, leave a detected file blocked. Check Windows Security → Virus & threat protection → Protection history for the exact filename and detection name. Send those details to the antivirus vendor, or contact me on the WSG Discord linked from the WeSimGlide website.

Keep antivirus protection enabled. Do not exclude your Downloads, MSFS or mod folder. A matching checksum confirms which release you downloaded; it does not establish that an antivirus alert is wrong.

Do I need ReShade, OFXR, or a particular headset?

ReShade: the required components are built in. A separate full ReShade installation is not required. If you already use ReShade in MSFS, use the original Glass Cockpit DLSS Fix add-on instead of this standalone package.

OFXR: this package does not generate frames. If you want frame generation too, install and run the official OFXR Bridge separately, using settings suitable for your hardware. This mod does not change those settings.

Headsets: the fix is not restricted to a Pimax headset or runtime. It targets MSFS 2024’s D3D12 upscaling path for desktop and VR. Other headset/runtime combinations are not all validated; test on your own setup. Instrument results can vary by aircraft and upscaler.

Requirements: Windows x64, MSFS 2024 with DLSS or FSR upscaling, and the Microsoft Visual C++ x64 runtime needed by the DLLs. The control app uses Windows’ .NET Framework.

Do updates need an uninstall and reinstall?

No, not for a normal update. From v0.1.4 onward, the app checks for updates at launch. It downloads and verifies a newer package, closes briefly, then reopens itself. If the server is unavailable, the current app remains usable.

An app-only update does not need to change files in MSFS. If the simulator DLLs differ, the app enables Update; close MSFS before clicking it. Installed settings and original uninstall backups are kept. An interrupted update can also offer recovery through Update.

Coming from v0.1.3 or earlier? Close the control window and extract the complete current ZIP over your external mod folder once. Then open the new EXE. Keep your settings backups and SimulatorDirectory.txt.

What gets installed in the MSFS Content folder?

The installer adds dxgi.dll, StandaloneGlassGraphics.dll and StandaloneGlass.ini, plus an installation receipt and any needed backups. Existing conflicting mod files are replaced only after confirmation and are backed up for Uninstall.

It does not edit original MSFS binaries, headset files, OFXR settings or OpenXR registrations. Settings backups stay beside the external app; diagnostic logs can remain after uninstall. Unexpectedly changed files are preserved for review rather than silently removed.
