# Glass Cockpit Refresh v1.0.2.16

- Fixes all Settings controls becoming disabled after updating the official graphics DLL to v1.0.3.
- Removes the DLL version allowlist. Newer official DLL versions keep the settings already supported by the app available; an app update is needed only when the settings themselves change.
- Keeps the existing protection during install/update operations, incomplete installations, and while the ReShade add-on is running in MSFS.
- Preserves glass settings, shortcuts, uninstall backups and separate OFXR settings. The official graphics files are unchanged; this app update does not replace the DLL already installed in MSFS.
- Retains unversioned download filenames and the automatic compatibility-update route for older apps. No uninstall is needed: open the app normally to update.

Latest official release remains the default for installation. The offline bundle remains official v1.0.2; an installed v1.0.3 is kept. Existing screenshots and videos are retained.

Installer/settings support: siglr / WeSimGlide. Official graphics support: IFreemz.
